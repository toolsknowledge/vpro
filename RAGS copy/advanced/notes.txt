1) create the below folder
            RAGS
                advanced

2) create requirements.txt file
        RAGS
            advanced
                requirements.txt

        
        > cd advanced
        > python -m venv venv
        > source venv/bin/activate
        > python -m pip install -r requirements.txt

3) create main.py under backend directory
            RAGS
                advanced
                    backend
                        main.py

4) create .env file
                    backend
                        .env

5) create app.py under frontend directory

                advanced
                    frontend
                        app.py

6) lanuch the application

        Terminal-1
        **********
        > cd advanced
        > cd backend
        > python -m uvicorn main:app --reload

        Terminal-2
        **********
        > cd advanced
        > source venv/bin/activate 
        > cd frontend
        > streamlit run app.py
            (or)
        > python -m streamlit run app.py
