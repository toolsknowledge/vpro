Component
*********
    portion of webpage called as "Component"
    as a react developer, we are able to create more "than one" component
    these components are "reusable"
    we are able to include one component to another component


State
*****
    - component data called as state
    - state is mutable
    - useState() hook, used to define the state
    - useState() hook is the predefined hook
    - useState() hook, available in react package
    Ex.
            import { useState } from "react"        
            
    - {} called as expression / interpolation
    - {} used to display the results on webpages
