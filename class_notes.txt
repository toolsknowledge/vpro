Python
******
    Python is the high level "programming Language"
    
    "Python" is the prerequisite to build
    1) ML   2) DL   3) NLP  4) Gen AI   5) Agentic AI   6) FastAPI  7) Automation Script

    Python supports so many "Libraries" to build "High End Applications"

    1) numpy - numerical python

    2) tensorflow & pytorch - DL

    3) nltk - NLP

    4) LangChain & LangGraph - Agentic AI

    5) pandas - Excel Files / CSV Files / JSON Files

    7) matplotlib - Draw Graphs / Plots

    8) seaborn - Rich Graphs

    9) fastapi - used to develop Rest API'S - GET / POST / PUT / DELETE / .......

    10) uvicorn - used to run fastapi calls

    11) rich - display styles output
            Ex.
                    Green color display
                    Table display
                    progress Bar
                    bold Text
                    panel display
                    ---
                    ---
                    ---

    "pip" is the tool, used to download libraries

    python file extension must be ".py"

    we will execute with the help of either python / python3 tools

    Ex.
            python demo.py
                (or)
            python3 demo.py

    "#" used to "comment" the code
    
    commented code wont execute by python / python3

    comments increases "application readability"

    "print()" is the predefined function, used to display "output on console"
