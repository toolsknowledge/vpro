Rules to declare variables
1) variable declaration should contain
        a-z,A-Z,0-9 and _ (underscore)

2) variable declaration should not start with "digits"

3) we are unable to use "predefined keywords" as variables
    Ex.
            if,else,elif,match,class,.........

            import keyword
            print(keyword.kwlist)

Ex.
            msg123
            msg123_
            msg_123
            123msg (invalid)
            _msg
            $msg123 (invalid)
            msg$123 (invalid)
            if (invalid)
            class (invalid)
            match (invalid)

integer
*******
    1) positive,negative or zero we can call "integer" datatype
    Ex.
            num1 = 100
            num2 = -100
            num3 = 0

    2) never start integer with "0"
    Ex.
            num1 = 0100 (Error)

    3) number allows "underscore"

    Ex.
            num1 = 10_000

    4) Boolean (True/False) is the Child DataType of integer datatype

        True - 1
        False - 0

    5) in python, we are able to store large numbers

            large = 123456789123456789123456789123456789123456789123456789123456789

    6) hexadecimal(0x),octal(0o) and binary(0b) automatically converted to "decimal numbers"
    
    7) datatype conversion possible
            "10" ---> 10 int()
        
string
******
        "collection of characters" called as "string"
        we will represent string in "3 ways"
        1) "" (double quotes)
        2) '' (single quotes)
        3) """ """ (tripple quotes)

        """ """ are used to declare the "paragraphs"


Boolean
*******
        we have two Boolean values
        1) True
        2) False

        Boolean values are case sensitive

        Boolean is the child class of "integer"

        True - 1
        False - 0
