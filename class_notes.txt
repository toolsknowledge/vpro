Python

    Python supports so many "Libraries" to build "High End Applications"

    1) numpy - numerical python

    2) tensorflow & pytorch - DL

    3) nltk - NLP

    4) LangChain & LangGraph - Agentic AI

    5) pandas - Excel Files / CSV Files / JSON Files

    7) matplotlib - Draw Graphs / Plots

    8) seaborn - Rich Graphs

    9) fastapi - used to develop Rest API'S - GET / POST / PUT / DELETE / .......

    10) uvicorn - used to run fastapi calls

    11) rich - display styles output
            Ex.
                    Green color display
                    Table display
                    progress Bar
                    bold Text
                    panel display

                    ---

    "pip" is the tool, used to download libraries

    python file extension must be ".py"

    we will execute with the help of either python / python3 tools

    Ex.
            python demo.py
                (or)
            python3 demo.py

    "#" used to "comment" the code

    comments increases "application readability"

    "print()" is the predefined function, used to display "output on console"
    

Variables
*********
        variables are used to store the data
        Ex.
                msg = "VPro"
                print(msg)
Rules to declare variables

1) variable declaration must contain a-z, A-Z, 0-9, $ and _
        Ex.
                msg
                msg123
                msg$123
                MSG321
                msg_
                _x 
                msg#123 (not valid)

2) variable declaration should not start with digits (0-9)
        Ex.
                        123msg (invalid)
                        msg_123

3) we can't use predefined keywords as variables

                import keyword
                print(keyword.kwlist)

                ['False', 'None', 'True', 'and', 'as', 'assert', 'async', 'await', 'break', 'class', 
                'continue', 'def', 'del', 'elif', 'else', 'except', 'finally', 'for', 'from', 'global', 'if', 
                'import', 'in', 'is', 'lambda', 'nonlocal', 'not', 'or', 'pass', 'raise', 'return', 'try', 
                'while', 'with', 'yield']


                class = "Morining" (Invalid) 

                is = "Hello" (Invalid)

                yield = "Welcome" (Invalid)
