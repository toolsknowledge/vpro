variables
*********
    variables are used to store the data
    Ex.
        int     Ex. 100
        float   Ex. 100.12345
        string  Ex. "VPro" / 'Hello' / """Welcome"""
        boolean Ex. True / False
        list    Ex [1000,200,300,400,500] --> [] / mutable (allows modifications)
        tuple   Ex (100,200,300,400,500,"Vikas) --> () / immutable (wont allows modifications)
        dictionary Ex {"key1":100, "key2": 200}     / keys are "immutable" and values are "mutable"
        None    
        Set    Ex. {100,100} -- {100} / never allows the "duplicates"
