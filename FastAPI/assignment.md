FastAPI + MongoDB Atlas — Student Assignments
Build a FastAPI application using MongoDB Atlas. Implement CRUD operations, user registration, login with JWT, and token-based authentication.

Assignment 1: Employee Management
- Database: cmp_db
- Collection: employees
Create APIs to add, view, update, and delete employee records. Implement registration and login. Protect all employee APIs using JWT authentication.

Assignment 2: Product Management
- Database: shop_db
- Collection: products

Create APIs to manage products with name, price, quantity, and category. Implement user registration, login, and JWT-protected product APIs.
Assignment 3: College Management
- Database: college_db
- Collection: students
Create APIs to add, view, update, and delete student records. Implement registration, login, and JWT authentication for all student APIs.

Assignment 4: Library Management
- Database: library_db
- Collection: books
Create APIs to manage books with title, author, and availability status. Implement user registration, login, and JWT-protected book APIs.

Assignment 5: Hospital Management
- Database: hospital_db
- Collection: patients
Create APIs to manage patient records with name, age, and department. Implement registration, login, and JWT authentication for all patient APIs.

Assignment 6: Course Management
- Database: training_db
- Collection: courses
Create APIs to manage courses with course name, duration, and fee. Implement user registration, login, and JWT-protected course APIs.

Assignment 7: Employee Attendance
- Database: attendance_db
- Collection: attendance
Create APIs to record, view, update, and delete employee attendance with employee name, date, and status. Protect all APIs using JWT authentication.

Assignment 8: Movie Management
- Database: movies_db
- Collection: movies
Create APIs to manage movies with title, genre, release year, and rating. Implement registration, login, and JWT-protected movie APIs.

Common requirements for all assignments
1. Use FastAPI and MongoDB Atlas.
2. Implement Create, Read, Update, and Delete operations.
3. Implement user registration with password hashing.
4. Implement login and generate a JWT token.
5. Protect all CRUD endpoints using JWT authentication.
6. Test all APIs using Swagger UI.
