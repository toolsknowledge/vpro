- DataBases are used to persist the data
- we have three types of DataBases
    1) SQL
    2) NoSQL
    3) VectorDBS

- SQL DataBases are used to maintain the structured data (Tables)
    Ex.
            Oracle
            MySQL
            SQLServer
            ---
            ---
            ---
- NoSQL DataBases are used to maintain the unstructured data (Objects)
    Ex.
            MongoDB
            CassandraDB
            ---
            ---
            ---
- VectorDBS are used to store the vectors/embeddings
- LLM'S only understands embeddings
    Ex.
            chromadb
            faiss
            pinecone
            Qdrant (Oracle)
            pgvector (Postgress)

    reading the data from Backend called as GET Request
    sending the new data/adding the new record to Backend called as "POST" Request
    updating/modifying Backend data called as PUT Request
    updating partial data called as PATCH Request
    deleting existed data called as DELETE Request
